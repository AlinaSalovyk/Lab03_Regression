## 🎯 Лабораторна робота №3: Основи регресійного моделювання

### Мета дослідження
Побудова та оцінювання прогностичних регресійних моделей для числової неперервної цілі `final_score_pct` (підсумковий бал студента від 0 до 100%) на базі інтегрованого масиву з **289,161 спостереження**. Дослідження виявляє ступінь впливу поточного GPA, цифрової регулярності в LMS та психологічного дистресу (стрес, вигорання, сон) на фінальний результат до моменту завершення семестру.

### Сформульовані та перевірені гіпотези
* **$H_1$ (Академічний фундамент):** GPA є домінуючим позитивним лінійним предиктором ($\beta_{\text{GPA}} = +0.843, p < 0.001$). **[Підтверджено]**
* **$H_2$ (Руйнівний дистрес):** Хронічний стрес ($\beta = -1.74$) та вигорання ($\beta = -2.08$) завдають безпосереднього удару по успішності (до -12–15% балів). **[Підтверджено]**
* **$H_3$ (Нелінійність і сплайни):** Залученість має пороговий нелінійний характер, тому модель GAM зі сплайнами відвідуваності перевершує лінійну OLS за метрикою RMSE ($10.93\%$ проти $11.52\%$). **[Підтверджено]**

### Результати моделювання на тестовій вибірці (Test Set, $N = 57,833$)

| Модель | Test RMSE | Test MAE | Test $R^2$ | Max Error | Опис специфікації |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **0. Baseline (Mean Only)** | $21.41\%$ | $17.85\%$ | $0.000$ | $61.68\%$ | Константний орієнтир без інформації про студента |
| **1. Multiple Linear (OLS)** | $11.52\%$ | $9.70\%$ | $0.710$ | $43.76\%$ | Базова множинна лінійна регресія (15 предикторів) |
| **2. OLS + Interactions & Poly** | $11.46\%$ | $9.65\%$ | $0.713$ | $\mathbf{41.49\%}$ | Модель із взаємодією $\text{GPA} \times \text{Distress}$ та поліномом відвідуваності |
| **3. Non-linear GAM (Splines)** | $\mathbf{10.93\%}$ | $\mathbf{9.05\%}$ | $\mathbf{0.739}$ | $45.22\%$ | Узагальнена адитивна модель зі згладжувальними сплайнами (`mgcv::bam`) |

## ⚙️ Відтворюваність результатів (Reproducibility)

### Системні вимоги:
* **Операційна система:** Windows 10/11 x64, macOS або Linux.
* **Середовище виконання:** R версії $\ge 4.3.0$ (протестовано на **R 4.5.3**).
* **Quarto CLI:** версії $\ge 1.4$ (для збирання `.qmd` файлів у HTML).

### Необхідні R-пакети:
Встановлюються стандартною командою в R консолі:
```r
install.packages(c("dplyr", "ggplot2", "readr", "scales", "cowplot", "broom", "mgcv"))
```

### Запуск повного пайплайну з нуля:
Для генерації всіх моделей, діагностичних графіків, таблиць та перевірки на тестовій вибірці достатньо виконати:
```powershell
Rscript scripts/build_regression_pipeline.R
```

### Збирання звітів та презентацій Quarto:
```powershell
# Збирання звіту Лабораторної №3
quarto render reports/report_lab3.qmd

# Збирання інтерактивної презентації Revealjs
quarto render reports/presentation_lab3.qmd
```
